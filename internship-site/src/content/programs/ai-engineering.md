## Start with curiosity. Build with purpose.

You do not need to arrive knowing how to build an AI application. Start with programming fundamentals, practise in Python, and connect each new skill to a working project.

This is a project-based training internship for college students. The learning journey combines guided exercises, independent practice, and portfolio projects. Enquire about the available delivery arrangements, timetable, and next batch.

## Modern AI engineering, one foundation at a time

RAG, tool calling, and multi-agent workflows become easier to understand when you build the software around them. Begin with Python, APIs, and data, then use guided projects to connect these AI capabilities to a React application. Practise checking answers, handling failed tools, and explaining what your system can and cannot do.

## What you will work towards

- Write, debug, and test Python programs with confidence.
- Connect a React interface to a Python API and PostgreSQL database.
- Build a document assistant that retrieves evidence and cites its sources.
- Design agent workflows with tools, boundaries, and human review.
- Explain your code, evaluate your AI application's behaviour, and present a portfolio case study.

## Before you begin

Bring a laptop, a reliable internet connection, basic computer skills, and time for regular practice. No previous AI experience is required. The learning plan assumes approximately 12–15 hours each week; confirm the teaching timetable and setup requirements when you enquire.

## Learning through projects

Each stage has a working output. Keep your code in GitHub, document the decisions you make, and test the parts that can fail. Your final portfolio should explain the problem, your implementation, the evidence that it works, and what you would improve next.

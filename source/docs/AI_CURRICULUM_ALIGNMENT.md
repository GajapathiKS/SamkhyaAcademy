# AI Curriculum Alignment

## Forward Deployed AI Engineering

Primary career progression:

**Full-Stack / Backend Developer -> GenAI Developer -> Production AI Engineer -> AI FDE**

Supported entry stacks:
- Python / FastAPI
- C# / .NET / ASP.NET Core
- Java / Spring Boot
- Node.js / TypeScript / NestJS or Express

The course is not Python-only. AI concepts are stack-agnostic; reference implementations can be completed in a supported backend stack.

FDE layers:
1. Engineering readiness
2. AI Engineering - LLMs, RAG, agents, MCP, tools, memory, voice and multimodal applications
3. Production AI - evaluations, guardrails, cloud, CI/CD, observability, security, scalability and cost
4. Enterprise integration - SSO/OIDC, RBAC, APIs, databases, SharePoint, SAP, CRM/service platforms and legacy systems
5. Solution architecture - RAG vs fine-tuning vs SLM vs agent vs deterministic workflow, including voice/multimodal choices
6. Customer/business problem solving
7. Forward deployment and outcome ownership

## Applied Machine Learning Engineer

1. Data & ML foundations
2. Deep learning
3. Computer vision, NLP, speech and multimodal AI
4. LLM / SLM engineering - fine-tuning, PEFT, LoRA/QLoRA, quantization, distillation and educational SLM training
5. Production ML / MLOps

## Forward Deployed AI Leadership

Leadership does not code these systems. Leaders learn enough to make investment and governance decisions across:
- hosted LLMs
- RAG
- fine-tuning
- SLMs
- voice AI
- computer vision / multimodal AI
- production readiness
- enterprise integration
- risk, economics and adoption

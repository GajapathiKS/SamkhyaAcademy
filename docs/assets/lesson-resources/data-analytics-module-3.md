# Data Analytics Path

## Module 3: Python and Statistics

Explore a dataset without confusing patterns with proof.

### 3.1 Pandas workflows

A Pandas workflow should make selection, transformation and aggregation readable. Inspect dtypes and nulls before calculating. Avoid accidental chained updates or hidden mutation by working with explicit intermediate results.

### 3.2 Exploratory analysis

Exploratory analysis checks distributions, outliers and relationships before a final narrative. Investigate unusual values rather than deleting them automatically. A surprising observation may be a data error or a real part of the population.

### 3.3 Practical statistics

Choose summary statistics that fit the distribution and question. A mean can be sensitive to extreme values; a median answers a different question. Show variability and sample size instead of presenting one number as complete evidence.

### 3.4 Experiment interpretation

Experiment interpretation needs a design, outcome definition and appropriate uncertainty assessment. Distinguish randomized experiments from observational comparisons. Repeatedly searching for a favorable result can make an apparently convincing finding unreliable.

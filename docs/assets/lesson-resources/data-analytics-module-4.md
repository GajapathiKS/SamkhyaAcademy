# Data Analytics Path

## Module 4: BI and Storytelling

Communicate a decision with readable visuals and honest caveats.

### 4.1 Visualization principles

Choose visual encodings that fit the comparison. Use position and length for precise comparisons and label units. Avoid decorative effects that distort scale or imply precision the data does not support.

### 4.2 Dashboard design

A dashboard should support a small set of user decisions. Group related metrics, expose filters and show the reporting period. Include empty and missing-data states so an unavailable result is not mistaken for zero.

### 4.3 Stakeholder narrative

A stakeholder narrative connects the question, method, finding, limitations and proposed action. Distinguish the evidence from the recommendation. A clear caveat strengthens the decision when it explains what could change the conclusion.

### 4.4 Analytics capstone

The capstone combines a reproducible dataset, analysis, dashboard and recommendation. Make metric definitions and exclusions available. A screenshot alone does not demonstrate that another analyst can reproduce the result.

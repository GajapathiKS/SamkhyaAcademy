# Data Analytics Path

## Module 1: Analytics Foundations

Turn a stakeholder question into a metric that can be reproduced.

### 1.1 Business questions and KPIs

Define the decision before selecting a chart. A KPI needs a numerator, denominator, time window and eligible population. Counts and rates answer different questions; show both when population sizes differ.

### 1.2 Excel analysis

A spreadsheet analysis should preserve raw data and separate calculations from presentation. Use explicit ranges and inspect missing or inconsistent types. A formatted number is not proof that the underlying formula uses the right records.

### 1.3 Data quality

Data quality includes completeness, validity, uniqueness and consistency. Record exclusions and their effect on the result. Do not silently turn missing values into zeros because that changes the meaning of the analysis.

### 1.4 Analytical thinking

Analytical thinking distinguishes observation, interpretation and recommendation. Seek an alternative explanation for a pattern. A descriptive comparison does not establish causation, especially when groups differ in timing or selection.

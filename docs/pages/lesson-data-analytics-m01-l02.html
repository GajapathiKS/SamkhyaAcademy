Excel analysis

Analytics Foundations

Understand and apply

Excel analysis

A spreadsheet analysis should preserve raw data and separate calculations from presentation. Use explicit ranges and inspect missing or inconsistent types. A formatted number is not proof that the underlying formula uses the right records.

Why this matters in the module

Turn a stakeholder question into a metric that can be reproduced.

Module worked example

Cohort A: 80 completions / 100 eligible = 80%
Cohort B: 60 completions / 60 eligible = 100%
A has more completions; B has the higher completion rate
Check equal follow-up periods before comparing.

Interpret the result

A missing denominator can reverse the interpretation without changing any completion count.

Apply lesson 1.2

Explain how excel analysis affects the example above. Identify one assumption, change it, and describe what you would test before accepting the result.

Module knowledge check

Why show the denominator with a percentage?

Compare with the explanation

It reveals the eligible population and helps users interpret sample size and comparability.

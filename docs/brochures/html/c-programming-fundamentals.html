1Programming and C Foundations

Build a small temperature-reporting program and learn how source becomes an executable.

  1. 1.1Set up the C toolchainThe compiler translates C source and the linker resolves referenced functions.
  2. 1.2Variables and data typesA variable has a type, a value and a lifetime.
  3. 1.3Operators and expressionsOperators combine values, but their operand types influence the result.
  4. 1.4Input and outputFormatted output requires conversion specifiers that match the arguments.

You will produce: Compilable source, command transcript and input validation cases.

2Control Flow and Functions

Turn a one-off calculation into a reusable, testable function.

  1. 2.1ConditionsA condition selects a path based on an expression.
  2. 2.2LoopsA loop needs an initial state, continuation condition and progress toward termination.
  3. 2.3Functions and scopeA function has an input contract, output contract and local state.
  4. 2.4Debugging fundamentalsDebugging is hypothesis testing.

You will produce: Function contract and boundary-case test log.

Practice is part of every module

Work through the example, record your reasoning, complete the module assignment and compare your work with the review criteria.

3Arrays, Strings and Pointers

Represent a fixed set of readings without losing track of size and lifetime.

  1. 3.1ArraysAn array stores elements contiguously.
  2. 3.2StringsA C string is a character sequence ending in a null character.
  3. 3.3Pointer foundationsA pointer stores an address associated with a type.
  4. 3.4Pointers with arraysPointer arithmetic is meaningful within an array object and its one-past position.

You will produce: Array/string bounds worksheet and read-only function.

4Structures, Files and Capstone

Assemble a terminal record manager with explicit ownership and reliable file handling.

  1. 4.1Structures and enumsA structure groups related fields into a value; an enum names a finite set of states.
  2. 4.2File handlingOpening, reading, writing and closing a file can fail.
  3. 4.3Memory safety reviewReview every buffer length, object lifetime and allocation owner.
  4. 4.4Terminal application capstoneThe capstone joins input validation, functions, records and persistence.

You will produce: Terminal application, reproducible tests and project README.

Inside module 1: a worked example

#include <stdio.h>
int main(void) {
  int count = 3;
  double total = 71.0;
  printf("Average: %.2f\n", total / count);
  return 0;
}
// Compile: cc -Wall -Wextra report.c -o report

The output is Average: 23.67. Replacing total with an integer changes the division before formatting, so the intermediate result must be inspected.

How your work is reviewed

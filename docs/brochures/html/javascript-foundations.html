The module names, lesson sequence and evidence below match the course learning workspace.

1JavaScript Language Foundations

Build predictable transformations before connecting a user interface.

  1. 1.1Values and variablesUse const when a binding will not be reassigned and let when reassignment is necessary.
  2. 1.2FunctionsA function should make its inputs and returned result clear.
  3. 1.3Arrays and objectsArrays represent ordered collections; objects represent named properties.
  4. 1.4Errors and debuggingRead the error message and stack trace before changing code.

You will produce: Pure filtering function and input/output tests.

2Browser and DOM

Connect a course filter to an accessible browser interface.

  1. 2.1DOM selectionSelect the specific DOM element needed and handle a missing match.
  2. 2.2EventsAn event listener responds to an interaction after the page has loaded.
  3. 2.3Forms and validationBrowser validation improves feedback but does not secure a server.
  4. 2.4Accessible UI stateLoading, empty, error and success states need meaningful text, not only a color change.

You will produce: Accessible filtering page and interaction checklist.

Practice is part of every module

Work through the example, record your reasoning, complete the module assignment and compare your work with the review criteria.

3Asynchronous JavaScript

Represent asynchronous work without misleading loading or error states.

  1. 3.1PromisesA promise represents an eventual result or rejection.
  2. 3.2Async and awaitawait pauses the current async function, not the entire browser.
  3. 3.3Fetch and JSONfetch can resolve even when an HTTP response indicates an error.
  4. 3.4Loading and error statesRapid requests can finish out of order.

You will produce: Asynchronous page with explicit state transitions.

4Modules and Capstone

Package the browser project so another developer can run and test it.

  1. 4.1ES modulesES modules declare explicit imports and exports.
  2. 4.2Tooling basicsA development server provides a consistent origin and module loading.
  3. 4.3Testing conceptsTests compare an expected behavior with an observed result.
  4. 4.4Interactive web app capstoneDeliver the filter application with clear states, accessible controls and reproducible setup.

You will produce: Interactive app, tests and reproducible README.

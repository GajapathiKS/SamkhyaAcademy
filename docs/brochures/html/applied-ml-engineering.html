Detailed module curriculum · 1-3

Build the foundations.

The module names, lesson sequence and evidence below match the course learning workspace.

1Data, Math and Python Bridge

Prepare a reproducible dataset and a defensible prediction question.

  1. 1.1Python for dataUse Python transformations with explicit input and output shapes.
  2. 1.2Statistics essentialsStatistics helps describe variation and uncertainty.
  3. 1.3Data preparationDefine the prediction time before selecting features.
  4. 1.4SQL and visualizationSQL extracts records at a defined grain; visualization reveals distributions and quality problems.

You will produce: Dataset contract and leakage review.

2Classical Machine Learning

Compare simple models using an evaluation design that reflects deployment.

  1. 2.1Regression and classificationRegression predicts a quantity; classification predicts a category or class probability.
  2. 2.2Feature engineeringFeatures should encode information available at inference time.
  3. 2.3ClusteringClustering groups examples according to a representation and similarity choice.
  4. 2.4Metrics and model selectionSelect metrics that match class balance and error costs.

You will produce: Model comparison and evaluation memo.

3Deep Learning

Understand how neural networks learn and where training can fail.

  1. 3.1Neural network foundationsA neural network composes parameterized transformations.
  2. 3.2OptimizationOptimization updates parameters to reduce training loss.
  3. 3.3CNNsConvolutional layers share weights across spatial positions.
  4. 3.4Sequence and transformer foundationsSequence models operate on ordered representations; attention relates positions through learned scores.

You will produce: Training notebook, shape diagram and learning curves.

4Computer Vision, NLP and Multimodal

Evaluate perception tasks according to their actual outputs.

  1. 4.1Classification and detectionClassification labels an image; detection locates and labels objects.
  2. 4.2Segmentation, tracking and OCRSegmentation labels regions, tracking associates observations across time and OCR extracts text.
  3. 4.3NLP and transformersNLP workflows require a defined text unit, label policy and evaluation set.
  4. 4.4Voice and multimodal workflowsCombining voice, image and text does not remove uncertainty from the inputs.

You will produce: Perception evaluation and error analysis.

5LLM and SLM Engineering

Adapt a model only after defining the behavior and evaluation gap.

  1. 5.1Dataset preparation and evaluationTraining data needs provenance, consistent formatting and an explicit label policy.
  2. 5.2Supervised fine-tuningSupervised fine-tuning adjusts a pretrained model using target examples.
  3. 5.3PEFT, LoRA and QLoRAParameter-efficient adaptation updates a subset or additional low-rank parameters.
  4. 5.4Quantization and distillationQuantization reduces representation precision; distillation trains a smaller model to approximate useful behavior.

You will produce: Adaptation experiment and model card.

6Educational Transformer and MLOps

Connect an educational transformer to a reproducible serving workflow.

  1. 6.1Tokenizer and embeddingsA tokenizer maps input text to token identifiers; embeddings map identifiers to learned vectors.
  2. 6.2Transformer blocks and training loopA training loop performs forward computation, loss evaluation, gradient computation and parameter updates.
  3. 6.3Model servingServing needs a versioned input contract, resource limits and health checks.
  4. 6.4Monitoring, drift and capstoneMonitoring tracks data quality, latency and task outcomes after deployment.

You will produce: Educational model, serving prototype and MLOps report.
